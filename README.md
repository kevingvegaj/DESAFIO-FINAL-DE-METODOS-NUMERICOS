# Proyecto Final de Métodos Numéricos

## Descripción

Aplicación web desarrollada en JavaScript para la simulación y análisis de problemas relacionados con:

- Sistemas de ecuaciones lineales
- Ecuaciones diferenciales ordinarias
- Interpolación numérica
- Integración numérica
- Raíces de ecuaciones no lineales

## Métodos Implementados

### Sistemas Lineales

- Jacobi
- Gauss-Seidel
- Factorización LU

### Ecuaciones Diferenciales

- Euler
- Heun
- Runge-Kutta de cuarto orden

### Interpolación

- Lagrange
- Newton

### Integración

- Trapecio
- Simpson 1/3
- Simpson 3/8

### Raíces

- Bisección
- Newton-Raphson
- Secante

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Chart.js
